# 🧩 Waybar

Waybar desktop configuration.

## ⚙️ Configure Waybar

Choose compact or standard height for the upper panel. The native panel helper inspects the active session for available battery, network, audio and backlight controls. Reload Waybar in the desktop session after changing the files.

Install and Update use signed Debian package metadata on the supported target. Keep session and boot dependencies while another component consumes them.
