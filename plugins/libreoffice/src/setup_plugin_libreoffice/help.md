# 🧩 LibreOffice

LibreOffice workstation plugin.

## 📦 Installation

Use Install or Update to review the signed Debian package transaction and target architecture. The backend checks the package versions after applying the confirmed plan.

## ⚙️ Preferences

Open Tools → Options to edit the active LibreOffice user profile. Open Tools → Options → Load/Save → General to review AutoRecovery and backup settings. [Official documentation](https://help.libreoffice.org/).

## 🧹 User data

User profiles and documents are excluded from application package removal.


## ⚙️ Named launch profiles

Choose the Start Center, Writer, Calc or Impress in this plugin’s Settings. Select Save application launcher, enter a stable ID and menu label, and review the precise desktop entry. Each ID creates a separate application-menu shortcut in the user data directory. Its fixed command uses the selected program option. The managed-file receipt supports restore and detects later edits. [LibreOffice startup parameters](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html).
