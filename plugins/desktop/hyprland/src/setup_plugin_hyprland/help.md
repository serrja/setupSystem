# Hyprland

## ⚙️ Configure Hyprland

Set up the ordinary user's compositor session, launcher, portal and keyboard. Configure Waybar, Foot and Hyprlock separately. Saving a monitor layout checks an active output and its advertised modes before publishing the rule. Test a monitor layout for twelve seconds before saving it. The temporary test restores the original mode and checks the output again. Start the compositor from a local authenticated session.

Install and Update use signed Debian package metadata on the supported target. Keep session and boot dependencies while another component consumes them.
