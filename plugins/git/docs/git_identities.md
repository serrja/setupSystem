# 🔐 Git author identities

## ⚙️ Plugin actions

Configure an identity for repositories under a directory, import an existing repository’s author settings or explicitly apply an identity to one checkout. Open Git → Actions and review the fragment and target configuration path before applying.

Install GitHub CLI on its own plugin page when you want hosting access. After your desktop is ready, use that page to sign in, check an account or sign out. In Git, select the authorized host to upload an SSH public key or revoke a key recorded as created by Git. The plan displays the host, account, remote key ID and fingerprint before revocation. [Git configuration](https://git-scm.com/docs/git-config).
