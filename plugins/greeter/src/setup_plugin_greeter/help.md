# 🧩 Greeter

Graphical login and recovery.

## 🔐 Enable graphical login

Install supplies the greetd, cage and gtkgreet packages. Activate login reviews the session launcher, ordinary account, target, PAM display manager and managed paths before enabling greetd. Existing or unverified session configuration blocks a conflicting change.

Activation changes the default systemd target and preserves a local TTY recovery path. The current session continues running. Test a new login on an authorized disposable Debian target before treating the installation as accepted.
