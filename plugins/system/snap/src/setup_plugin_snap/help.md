# Snap

## 📦 Debian runtime

Install or update `snapd` from the reviewed Debian package plan. If its service is inactive after package installation, choose **Start Snap service**. In **List installed snaps**, Preview reads the local daemon and displays active and disabled revisions, versions, tracking channels and notes. Open Telegram to install its application. [Install snapd on Debian](https://snapcraft.io/docs/installing-snap-on-debian)

## 🧹 Ownership

The inventory includes existing snaps. A successful inventory grants no ownership. Removing a managed runtime requires an empty inventory, no retained snapshots and no active snapd changes. Resolve application data and shared runtime requirements in their owning application or Snap's native tools first. [Snap data snapshots](https://snapcraft.io/docs/how-to-guides/manage-snaps/create-data-snapshots/)
