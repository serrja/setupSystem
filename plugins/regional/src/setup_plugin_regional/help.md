# 🧩 Regional settings

Independent Debian regional settings.

## ⚙️ Configure Debian regional settings

Install regional tools if Debian locale and keyboard data are missing. Select timezone, UTF-8 locale or keyboard layout as a separate action. Preview reads the available choices and current setting. Apply repeats these checks on the target. Locales may require generation. Keyboard changes use Debian's console configuration. Backups for changed configuration are retained under the system recovery directory.
