# ChatGPT

## 📦 Installation

Use Install or Update to review the signed Debian package transaction and target architecture. The backend checks the package versions after applying the confirmed plan.

## ⚙️ Preferences

Open the official ChatGPT application and sign in using its account dialog. Open ChatGPT Settings to manage personalization and account preferences. [Official documentation](https://learn.chatgpt.com/docs/linux/linux-app).

## 🧹 User data

User profiles and documents are excluded from application package removal.
