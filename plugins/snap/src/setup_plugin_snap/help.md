# 🧩 Snap

Install snapd from the reviewed Debian package and start its service if needed. **List installed revisions** reads the local daemon. Snapd removal checks every revision, saved snapshot and in-progress change.

Choose **Install applications**, **Update applications**, **Remove applications** or **Check applications**. Select catalog entries and preview their exact revisions. Installation and update resolve the stable release for the supported architecture and verify the packaged Snap ID, publisher ID, publisher validation, confinement and required shared runtimes. Removal creates and verifies a data snapshot before removing the selected application. Review snapshots in the native Snap tools.

The catalog contains Firefox, Neovim, Obsidian, Spotify and Telegram Desktop. Firefox, Spotify and Telegram Desktop use verified publisher accounts. Neovim and Obsidian use pinned publisher accounts with Store validation `unproven` and require classic confinement. Obsidian and Spotify are available on amd64; the other entries support amd64 and arm64. A classic application can access host files according to its own behavior, so review that confinement in Preview before applying. Sign in and manage application data inside the official clients. Removing setupSystem preserves installed applications and their data.
