# 🧩 Projects and templates

Canonical project catalog and Copier workflows.

## 🧩 Work with a project

Inspect the catalog to find existing checkouts by exact root and canonical fetch and push URLs. Prepare directories creates the catalog's owner folders. The catalog includes projectRules. Open an active project in Neovim or Codex using its canonical root. In a Wayland session, Foot runs under the current user’s service manager. Check available template versions before selecting a release.

## 📦 Use Copier

Template creation and update require the official Copier 9.x CLI (9.10 or newer). Cache an annotated release, create a project in a new destination or update a clean Git repository using its recorded answers. Each Preview binds the upstream tag and commit. Choose offline mode to use a previously verified source cache. Resolve any Copier conflict in the preserved worktree. Removing the extension preserves repositories and their history.
