# Workspace projects

Open **Projects and templates** to inspect checkouts, prepare selected directories or launch an editor. Its packaged project catalog holds the canonical owners, project IDs, Copier aliases and origins, including `pokerlost/projectRules`. The default root is `$HOME/Projects`.

## 📂 Select a checkout

A project must be an exact Git working tree with the expected effective fetch and push origin. The picker preserves existing files, local commits, refs and dirty changes. Preparing the catalog directories does not clone or initialize repositories. Template creation and updates have their own previews. [Project templates](../../../docs/templates.md).
