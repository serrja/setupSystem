# 🧩 Neovim

Neovim workstation plugin.

## ⚙️ Editor settings

Choose editor languages, Wayland clipboard and login-editor integration, then preview Configure. The configuration includes the Catppuccin Mocha Green colors, key mappings, local project detection and search exclusions. Existing plugin checkouts under the editor data directory load offline. Plugin downloads and automatic updates are disabled at startup.

## 🧹 Data

Full cleanup removes the exact compiler output files still matching their recorded digests and modes. It preserves changed parsers, plugin Git repositories and edited documents. The file journal retains prior settings for recovery.
