# Telegram Desktop

## 📦 Installation

Use Install or Update to review the signed Debian package transaction and target architecture. The backend checks the package versions after applying the confirmed plan.

## ⚙️ Preferences

Open Telegram Desktop → Settings → Add Account. Complete the native sign-in and check Active Sessions. Open Settings → Notifications and Sounds to select desktop notification behavior. [Official documentation](https://desktop.telegram.org/).

## 🧹 User data

User profiles and documents are excluded from application package removal.
