# Obsidian

## ⚙️ Vault settings

Choose an existing vault or use Create vault for a new, empty folder. Select that folder in the native vault manager. The CLI requires a compatible installer and explicit enablement in Settings → General. Keep this vault open while changing its theme or a core feature. The backend verifies the vault path for every such action. [Obsidian CLI](https://obsidian.md/help/cli).

## 🔐 Accounts and extensions

Use Obsidian's account and Sync dialogs. Review community plugin publishers individually. Restricted mode is controlled in Obsidian. [Plugin security](https://obsidian.md/help/plugin-security).

## 🧹 User data

Vault folders, notes and attachments are excluded from cleanup. [Obsidian storage](https://obsidian.md/help/data-storage).

## ⚙️ Native hotkeys

Inspect command shortcut reads the active vault’s current assignment for the selected command ID. Change its binding under Settings → Hotkeys, then inspect it again. The CLI documents shortcut lookup and enumeration. [CLI command reference](https://obsidian.md/help/cli).
