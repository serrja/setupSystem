# Firefox ESR

## 🔐 Enterprise policies

Choose a tracking protection level and HTTPS-only mode. Enabling the optional extension explicitly authorizes the uBlock Origin publisher from Mozilla Add-ons. Preview shows the system policy file. Restart Firefox and check `about:policies` for runtime acceptance. Existing locked preferences require administrator review. [Firefox policy documentation](https://support.mozilla.org/en-US/kb/customizing-firefox-using-policiesjson).

## 🧹 User data

Bookmarks, login data, cookies and browser profiles stay outside the plan.
