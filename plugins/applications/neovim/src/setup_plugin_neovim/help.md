# Neovim

## ⚙️ Editor profile

Choose language profiles, Wayland clipboard and login-editor integration, then preview Configure. The profile includes the Catppuccin Mocha Green colors, key mappings, local project detection and search exclusions. Existing plugin checkouts under the editor data directory load offline. Plugin downloads and automatic updates are disabled at startup.

## 🧹 Data

Git repositories and edited documents stay outside the editor configuration plan. The file journal retains prior settings for recovery.
