# Hyprlock

## ⚙️ Configure Hyprlock

The native Hyprlock session uses the shared login-screen palette, input geometry and typography. The password goes to Hyprlock/PAM. Only the owner of the locked session can unlock it. A new greeter login is a separate action.

Install and Update use signed Debian package metadata on the supported target. Keep session and boot dependencies while another component consumes them.
