# Neovim and language tools

## ⚙️ Plugin actions

Open Neovim and review the package installation. Save your language and clipboard choices, then run Configure, Install editor plugins, Install parsers and Verify editor. Installs pin the reviewed Git commits. Editor startup uses the local plugin checkouts.

Choose the corresponding language toolchain in the catalog. The TypeScript and Vue profile uses the verified npm generation. The headless editor check runs in a temporary project and reports parser, server and formatter failures. Press `<leader>ff` for files, `<leader>fg` for search, `-` for Oil and `<leader>cf` for formatting. [Neovim documentation](https://neovim.io/doc/user/).
