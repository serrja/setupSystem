# Project templates

Open Templates in **Working environment**, choose Python, Typer, FastAPI or service, and list its releases. Template creation asks for the destination and project name. The Python template also accepts a library, service or native profile. Review the selected source, version and commit before applying.

Copier runs as the current user. Install the official Copier CLI before using template creation or updates. The template adapter accepts catalog origins and annotated version tags. An explicit cache operation prepares an offline copy. Offline mode requires verified cached bytes.

## 📁 Create or update a project

Create requires a new or empty destination. Update checks the existing Copier answers and origin. Template tasks stay disabled. Review any merge conflicts before committing a generated project. [Copier documentation](https://copier.readthedocs.io/).
