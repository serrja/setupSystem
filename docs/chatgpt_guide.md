# ChatGPT Desktop

Select ChatGPT Desktop in **Working environment**. Preview resolves the official Linux package using OpenAI's signed Debian source and a dedicated packaged keyring. APT checks fresh indexes in a private run directory. Apply compares the package transaction again before installation. Review any source or architecture error shown by Preview. A retry uses the same signature checks.

Workspace Inspect shows when the last explicit ChatGPT Apply checked the signed indexes and whether verification succeeded. A failed source check is separate from catalog availability. Complete account authentication in ChatGPT after installation. [Official Linux installation guide](https://learn.chatgpt.com/docs/linux/linux-app).
