# Workstation applications

## 🧩 Installed extensions

Select a program in the catalog. Its Overview identifies the extension, and Check inspects the program on this machine. Save settings before requesting an action. Preview shows the resolved resources, warnings and required permissions for that action. Each extension includes offline Help and a reference generated from its models.

| Plugin | Actions |
| --- | --- |
| Git | Configure conditional identities, apply a repository profile and manage hosting keys. |
| Docker | Choose daemon mode, manage services and contexts or review one unused image for removal. |
| Codex | Install the official CLI, choose client-supported models and apply configuration per user or project. |
| Obsidian | Install the official package, select a vault and configure compatible native CLI features. |
| Happ | Manage named subscription references and export routing rules for native import. |
| Neovim | Select editor settings, plugin revisions, parsers and language tools. |
| Firefox ESR | Merge selected privacy settings into the system enterprise policy. |
| ChatGPT, Telegram Desktop and LibreOffice | Review package changes and open native account or settings instructions. |

## 🧹 User data and removal

Uninstall previews the application resources recorded as created. Existing packages, repositories, Docker volumes, vault notes and other personal documents require separate ownership decisions. Open the plugin’s Help for its specific cleanup behavior.

The program guides describe independent actions and the native steps required by external services. [Git profiles](git_profiles.md) · [Happ routing](happ_guide.md) · [ChatGPT Desktop](chatgpt_guide.md) · [Neovim](neovim_guide.md).
