# Versioning

The development candidate is `0.1.1.dev0`. It updates delivery verification and the sole checkout catalog for pokerWeb, pokerGateway and platformInfra. Existing repository locations, remotes, installer commands and permission grants are preserved. The inventory describes an existing repository; it does not create a checkout or grant access.

Read installed package metadata and `pyproject.toml` for the version. Check existing tags and published artifacts before selecting a release version. Development candidates do not overwrite a published artifact. CLI, catalog schema, managed configuration and platform support are separate compatibility contracts; Debian 12/13 remains the installer boundary.
