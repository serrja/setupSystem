# Области ответственности

| Роль | Чтение | Запись | Внешние действия |
| --- | --- | --- | --- |
| Координатор | Назначенные проекты и metadata | Приватный прогресс | Только разрешённое делегирование |
| Разработчик | Один repo и общая policy | Задача в этом repo | Без sudo/push по умолчанию |
| Reviewer | Diff и назначенный checkout | Собственный отчёт | Без публикации |
| Knowledge curator | Назначенный vault/Drive | Навигация и согласованная уборка | Без расширения доступа |
| System installer | Конкретный план и диагностика | Ресурсы плана | Адресный sudo |
| Release operator | Проверенные коммиты | Состояние публикации | Commit/push по текущему разрешению |

Файлы ролей описывают работу, но сами не создают subagents. Границы задаются permission profile и отдельной сессией. Смена каталога внутри сессии не пересобирает цепочку `AGENTS.md`.
