# Knowledge maintenance

Input: vault policy, chosen section and existing `project.json`/Drive links. Back up before moves, keep unique content and user checkmarks, update full-path links and nearest navigation. Verify available Drive metadata and rights without treating a shortcut as sync. Output mapping, changed links and checks that could not be run in the GUI.
