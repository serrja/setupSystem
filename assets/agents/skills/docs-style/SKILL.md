# Repository documentation

Input: current implementation and canonical docs. Keep one H1, short purpose, useful H2/H3, language-tagged commands and a single owner for each topic. Use a few meaningful emoji in navigation. Verify commands and relative links/anchors. Output changed pages and any unverified claims removed. Follow project language and preserve normative prompts.
